# 同梱サンプルデータについて

`sample_patents.csv`（全固体電池・960件）は、APOLLO の機能を体験するための**完全に架空の合成データ**です。

- 特許の本文（発明の名称・要約・請求の範囲）は、テーマ別の語彙テンプレートから機械生成した架空のものです
- 出願番号は架空の連番であり、実在の出願とは対応しません
- **出願人（蒼海自動車・白鳳電機産業 などの企業・大学・研究機関）はすべて架空の団体名であり、実在の企業・団体とは一切関係ありません**
- 発明者名は一般的な姓・名の無作為な組み合わせで、実在の人物とは無関係です
- 共同出願（出願人が複数の案件・約12%）は、完成車×電池・電池×材料・産学連携といった現実にありがちな提携構図を模した**架空の組み合わせ**です。実在の提携関係とは一切関係ありません

生成ロジックは `generate_sample.py` を参照してください（`python3 generate_sample.py` で再生成できます）。
