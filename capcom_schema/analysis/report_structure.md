## 2. deep_dive 全文コピールール

deep_dive.typの内容をreport.typにコピーする際の**最重要ルール**:

- **要約・圧縮・省略は一切禁止**
- 全セクション・全段落・全テーブルをそのまま転記する
- 許可される変更:
  1. 見出しレベル調整（`==`→`===`等）
  2. 冒頭の`#import`削除（report.typで1回だけimport）
  3. ヘッダ/フッタコメント削除のみ
- deep_dive.typが200行なら、report.typの対応章もほぼ200行であるべき

## 3. 各章の執筆ルール

### エグゼクティブサマリー
- 全deep_diveの統合要約
- Mission Objectiveへの回答を冒頭に配置する
- `exec-summary[...]` で囲む

### KPIダッシュボード
- `kpi-dashboard(cols: 3, kpi-card(...), kpi-card(...), ...)` で**ページまたぎ防止**
- `kpi-card("ラベル", "値", note: "補足")` で各KPIを表示
- **`cols` パラメータは 3 を厳守。4 以上は禁止**（A4幅で1カードあたり37mm以下になり、長い日本語の値テキストが文字単位で改行されて崩れる）。KPI が9個以上ある場合は `kpi-dashboard(cols: 3, ...)` を複数ブロックに分割する
- **ドル記号の禁止**: kpi-card の value / テーブルセル内で `$` や `\$` を使用禁止。通貨は「ドル」「USD」で表記する
- value テキストの長さに応じてフォントサイズが自動調整される(report_style.typ の `kpi-card` 関数が context で動的計算)。3文字以下=24pt、5文字以下=20pt、7文字以下=16pt、10文字以下=14pt、それ以上=12pt

### クロスモジュール統合分析（最低80行必須）
- 複数のdeep_diveを横断する洞察を新規執筆する（→ `analysis/cross_module.md`）
- NEBULA環境分析と特許分析の統合を含む
- **各パターンは「仮説→検証→結論」の3段構造で15-20行ずつ記述すること。1-2行の箇条書きで済ませるのは品質不合格**

### 仮説検証サマリー（⚠️ v7必須章）

**レポート中で導出した全ての仮説を一覧表にまとめ、各仮説の検証結果を明示する章。**
仮説を立てておいて検証せずに終わるのはレポートの信頼性を毀損する。必ずこの章で回収すること。

仮説のソース:
- NEBULA環境分析の「外部環境からの主要仮説」(H1-H5等)
- クロスモジュール分析の「仮説→検証→結論」
- 各deep_diveで「〜と推察される」「〜の可能性がある」と述べた推論

記載形式:
```typst
= 仮説検証サマリー

本レポートで導出した仮説とその検証結果を以下に整理する。

#styled-table(
  columns: (auto, 3fr, auto, 2fr),
  header: ("ID", "仮説", "判定", "根拠"),
  [H1], [政策駆動による出願ピーク形成], [✅ 支持],
    [ATLAS第2期のピーク（208件）とNEBULA政策イベント（プラ資源循環戦略2019年）が時系列的に一致],
  [H2], [ゴム複合材料の急成長], [✅ 支持],
    [Saturn Vクラスタ動態（CAGR +47.6%）、Explorerゴム関連キーワードGR197/137、MEGA旭化成リーダー象限が三重に裏付け],
  [H3], [バイオメディカル応用のホワイトスペース], [⚠️ 部分支持],
    [学術クラスタで151件（超領域📚Ⅰ）は確認。ただし日本語特許限定のため、米国出願での状況は未確認],
  [H4], [製紙大手→化学メーカーへのリーダーシップ移行], [✅ 支持],
    [MEGA PULSE: 製紙大手3社全て成熟/衰退象限、旭化成/東ソーがリーダー象限],
  [H5], [市場成長と特許減少の乖離], [✅ 支持],
    [市場CAGR +20%超 vs 特許CAGR -23%。技術の「研究開発投資→事業化投資」への段階移行を反映],
)

=== 未検証の仮説と今後の課題

上記の仮説のうち、H3（バイオメディカル応用）は日本語特許データの制約により完全な検証ができなかった。
グローバル特許データ（USPTO/EPO）を用いた追加分析を推奨する。
```

**品質チェック**: 仮説検証サマリーに以下が含まれていること:
- レポート内で導出した**全ての仮説**（漏れなく）
- 各仮説の**判定**（✅支持 / ❌棄却 / ⚠️部分支持 / ❓未検証）
- 各仮説の**根拠**（どのモジュールのどの分析結果で検証したか）
- **未検証の仮説**がある場合、その理由と今後の課題

クロスモジュール分析の記述例:
```
== P1: Saturn V x MEGA -- クラスタ成長と企業ポジション
**仮説**: Saturn Vクラスタ動態マップで「成長リーダー」に位置するクラスタは、
MEGA PULSEでもリーダー象限に位置する出願人が主導しているはずである。

**検証**: Saturn Vクラスタ0「タイヤ用ゴム」（14件、CAGR +254.5%）の主要出願人を
MEGA PULSEと照合すると、旭化成（CAGR +28.5%、リーダー象限）が7件（50%）を占める。
一方、日本製紙（CAGR -11.1%、成熟象限）はゴムクラスタに0件で、この成長領域から完全に不在。

**結論**: クラスタレベルの成長と出願人レベルの成長は強く相関しており、ゴム複合材料への
注力が企業の成長ポジションを規定している。日本製紙がリーダーシップを回復するには
ゴム・エラストマー領域への技術展開が不可欠。
```

### 各モジュール章の共通ルール
- 全evidence-boxに**データソースマーカー**を付与する（→ `analysis/common_framework.md` セクション5）
- **スナップショット画像は全章に必須**: `ls snapshots/` で利用可能な画像を確認し、各章の分析に最も関連する画像を `#snapshot-figure("../snapshots/xxx.png", caption: "説明")` で挿入する。画像のない章は不完全とみなす
- 特にランドスケープ（Saturn V/EAGLE/NEBULA学術）、動態マップ、トレンドチャート、共起ネットワークは必ず挿入すること

## 4. 結論章（= 戦略的提言）の執筆ガイド

- report.typの最終本文章として必須。4サブセクション構成
- `#conclusion-box("タイトル")[本文]` で主要結論をハイライト
- `#recommendation-card("高", "タイトル", "説明", timeframe: "短期(6ヶ月以内)")` で優先度付き推奨
- `#action-items("アクション1", "アクション2", ...)` で具体的ToDoリスト
- 推奨アクションは最低5件、各アクションに優先度（高/中/低）と時間軸（短期/中期/長期）を明記
- 全ての提言にはdeep_diveの分析結果からの論理的根拠を記載すること

## 5. 付録A: 分析条件一覧テンプレート

`voyager/context.json` と各モジュールJSONのメタデータから、以下の情報をテーブル形式で記載する:

```typst
= 付録

== A. 分析条件一覧

#styled-table(
  columns: (1fr, 2fr),
  header: ("項目", "内容"),
  [分析対象], [(context.jsonのdataset情報から)],
  [対象件数], [(total_patents)件],
  [対象期間], [(period)（出願年基準）],
  [分析実施日], [(date)],
  [分析ツール], [APOLLO v7.0.0],
  [テキスト埋め込み], [SBERT（paraphrase-multilingual-MiniLM-L12-v2）],
  [次元削減], [UMAP（n_neighbors=15, min_dist=0.1, metric=cosine）],
  [クラスタリング], [HDBSCAN（min_cluster_size=自動推定）],
  [テキスト前処理], [patiroha: Janome形態素解析 + NFKC正規化 + ストップワード除去 + 複合名詞結合],
  [共起ネットワーク], [(ノード数)ノード、(エッジ数)エッジ、Louvain コミュニティ検出],
  [動態分析], [CAGR x 活動量の4象限（MEGA PULSE）],
  [クラスタ動態], [累積件数 x CAGR（直近N年）の4象限マップ],
  [多様性指標], [HHI / Entropy / Gini],
)
```

※ 各パラメータの具体値は `context.json` と各モジュールJSONから読み取って記入すること。
※ CORE分類やNEBULA分析を実施した場合はそれらの条件も追記すること。

## 6. 付録B: 用語解説テンプレート

レポート中で使用した専門用語・分析手法について、非専門家でも理解できるよう解説テーブルを作成する:

```typst
== B. 用語解説

#styled-table(
  columns: (1fr, 3fr),
  header: ("用語", "解説"),
  [SBERT], [Sentence-BERT。文章単位の意味的類似度を計算するための事前学習済み言語モデル。各特許の要約文を384次元のベクトルに変換し、意味的な距離を定量化する],
  [UMAP], [Uniform Manifold Approximation and Projection。高次元データの構造を保持しながら2次元に次元削減する手法],
  [HDBSCAN], [Hierarchical Density-Based Spatial Clustering of Applications with Noise。密度ベースの階層的クラスタリング手法],
  [ノイズ（HDBSCAN）], [HDBSCANが既存クラスタのいずれにも分類しなかったデータ点],
  [CAGR], [Compound Annual Growth Rate（年平均成長率）],
  [c-TF-IDF], [class-based TF-IDF。クラスタ単位で文書を結合した上でTF-IDFを計算し、クラスタを判別する特徴語を抽出する手法],
  [HHI], [Herfindahl-Hirschman Index。市場集中度を測る指標。0に近いほど分散、1に近いほど集中],
  [Entropy], [Shannon Entropy。情報量の多様性を測る指標。値が高いほど分散（多様）],
  [Gini], [Gini係数。不平等度を測る指標。0＝完全平等、1＝完全不平等],
  [コミュニティ検出], [ネットワーク内で密に接続されたノード群を自動検出するアルゴリズム。本分析ではLouvain法を使用],
  [媒介中心性], [ネットワーク内のノードが他のノード間の最短経路上にどの程度位置するかを示す指標],
  [共起ネットワーク], [特許文書中で頻繁に同時出現するキーワードのペアをエッジで接続したネットワーク],
  [IPC], [International Patent Classification（国際特許分類）],
  [Fターム], [日本特許庁が独自に定義した技術分類体系],
  [クラスタ動態マップ], [各クラスタの累積件数（X軸）とCAGR（Y軸）をプロットした4象限マップ],
)
```

※ レポート中で使用した技術固有の用語（例: NeRF, 3D Gaussian Splatting等）も適宜追加すること。
※ 用語はアルファベット順・50音順にソートすること。
